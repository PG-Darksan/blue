# Bluesky 相互フォローチェッカー & Jev 女性抽出アプリ (`blue`)

Bluesky（AT Protocol）公式 API を用いた Android / Windows 対応の**相互フォローチェッカー**アプリです。
`nearby_insta` と同じく、TypeSafe AI の判断特化モデル **Jev (`jev-latest`)** を用いて「女性個人のアカウントのみ」を抽出・表示する機能と、フォロー解除・ミュート・ブロックの自動一括操作機能を搭載しています。

## 主な機能

1. **ログイン不要の相互フォローチェッカー**
   - 任意の `@handle`（例: `alice.bsky.social`）を入力するだけで、フォロー全件・フォロワー全件を取得し、**「片思い（未フォロバ）」「片思われ（フォロワーのみ）」「相互フォロー」「すべて」**に自動分類します。
   - 一覧内の任意のアカウントから「この人の相互・フォロワーを解析」をワンタップで辿ることも可能です。

2. **Jev (`jev-latest`) による女性アカウントのみ表示**
   - 画面右上の **「♀ 女性のみ」** ボタンを ON にすると、プロフィールアイコン画像（320×320 PNG に自動整形）と `@handle`・表示名・自己紹介文を Jev（`https://api.typesafe.ai/v1/systemone`）に渡して判定し、女性個人のアカウントのみを表示します（男性・店舗・企業・Bot・性別不明アカウントを非表示）。
   - 画面上部の費用バーおよび設定ダイアログから、リアルタイムの累計費用・起動中費用（USD / 日本円目安）・しきい値（40%〜85%）・接続テストを確認できます。判定結果は端末内に 90 日間キャッシュされ、再判定費用は掛かりません。

3. **アプリパスワードでのログイン・複数アカウント切替・一括自動操作**
   - Bluesky の「アプリパスワード（App Password）」で安全にログインでき（パスワード本体は保存せずセッショントークンのみ保持）、複数アカウントのワンタップ切替にも対応しています。
   - 個別または複数選択による **一括リムーブ（フォロー解除）・一括フォロー・一括ミュート・一括ブロック**（レート制限に配慮したウェイト＆中断ボタン付き）を実行できます。
   - **ミュート・ブロック管理画面**から、現在ミュート中・ブロック中のアカウント一覧の確認とワンタップ解除も行えます。

## ビルド方法

```powershell
# Android 用 APK のみビルド (dist/blue-0.1.0-android.apk に出力)
pwsh tool/build_release.ps1 android

# Android APK と Windows 実行ファイルの両方をビルド
pwsh tool/build_release.ps1
```
